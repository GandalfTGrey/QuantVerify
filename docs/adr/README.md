# Architecture Decision Records

ADR 记录已经接受、会影响多个模块或研究结论的技术决策。状态为 `Accepted` 的 ADR 是当前实现依据；若后续决策取代旧 ADR，旧文件保留并标记为 `Superseded`，不得静默改写历史。

冲突裁决顺序见 [ADR-0001](0001-architecture-governance-and-document-precedence.md)。
